航天基地这张图的问题不是难，是**信息太多**。八个出生位、核心五房、三种撤离、一堆钥匙卡，每局开局都要在几十秒里重新做一遍判断，判断一乱就死在半路。

所以这篇不写"要灵活应变"，只写固定动作。目标是：**落地看位置就知道往哪走，看到时间就知道该不该撤**。

## 先记三个时间点

| 时间 | 发生什么 |
|---|---|
| 开局约 9 分钟 | 水平试车间的丢包撤离开放 |
| 拉完双闸后 | 等 5 分钟，喷泉广场开 |
| 开局约 15 分钟 | 发射区大桥可以接飞升任务 |

这三个数字决定了后面所有决策。10 分钟是个分水岭——**过了 10 分钟还没拉第一个闸，就别想双闸了**，直接改丢包。

## 机密和绝密，差在哪

这是必须先分清的一件事，两个模式的公式完全不一样。

| | 机密 | 绝密 |
|---|---|---|
| 丢包名额 | **3 个** | **1 个** |
| AI | 中等，会找掩体会发呆 | 强，会包抄、会扔雷、听视范围更大 |
| 玩家密度 | 高（跑刀同行特别多） | 中等，但装备普遍更好 |
| 物资 | 蓝紫为主，偶尔出金 | 金红概率明显更高 |
| 死亡代价 | 有保险箱兜底 | 基本全损 |
| 适合谁 | 练路线、单排、攒钱 | 组排、装备齐、想出红 |

**最要命的是第一行。** 机密三个丢包名额，三人队正好一人一个，随便跑都撤得出去；绝密只有一个名额，单排来晚了就是白跑一趟——必须落地就把名额算进去。

我自己的打法是：机密拿来练路线和攒钱，绝密只在三个人都在、装备都齐的时候打。

## 公式：三段式

### 第 0–3 分钟：认位置，不搜东西

落地先做两件事：确认自己刷在哪、听三秒有没有交火。

这三十秒不要急着开门搜箱子。航天基地的出生点分布很挤，同一时间不止你一个人在动，**先搞清楚周围有几个人**比多开一个箱子值钱。

### 第 3–9 分钟：按路线吃三个点，只吃三个

不要贪。三个点是上限，吃完就往撤离方向挪。

| 刷在哪 | 固定顺序 |
|---|---|
| 西区大门 / 西侧 | 黑室 → 总裁室 → 码头 |
| 中控楼一带 | 中控楼 → 离心机室 → 浮力室 |
| 宿舍区（有三号楼卡） | 宿舍三号楼 → 中控楼 → 离心机室 |
| 宿舍区（没卡） | 中控楼 → 离心机室 → 浮力室 |
| 牢大 / 牢二 / 牢三 | 先听声，等中控打起来 → 上面四条任选一条 |
| 发射区 | 要么做飞升，要么直奔核心，二选一别犹豫 |
| 员二 | 先抢枪位，不搜，等这一波打完再吃残局 |

牢区那三个位置是最难受的。共识是"不要头铁往中控冲"——用空间换时间，等别人先交火。

### 第 9–13 分钟：按手上东西选撤离

这才是"公式化"的核心。不看局势，只看你包里有什么：

| 手上的东西 | 选哪个 | 理由 |
|---|---|---|
| 只有蓝紫，背包轻 | 丢包 | 弃包损失小，最快 |
| 出了金 / 红，但没进钥匙房 | 双闸（前提是 10 分钟前拉了第一个） | 能带包走 |
| 三人齐、时间宽裕、装备好 | 飞升 | 收益最高，也最招人 |

**第 13 分钟以后只走丢包。** 这时候再想去拉闸或者飞升，基本都是给自己找麻烦。

## 三条铁律

**一、拉闸等于报坐标。** 双闸的两个闸都会响，拉完立刻离开原地，不要在那儿等队友。

**二、丢包前先把值钱的塞进安全箱。** 背包丢下去就永久留在战场，只有安全箱、胸挂、口袋里的东西能带走。搜的时候就该分好级，别到撤离点才翻包。

**三、绝密先看名额。** 机密三个名额可以随便跑，绝密一个名额——出发前不确认，到了发现被占了，就是白跑一趟还暴露了位置。
