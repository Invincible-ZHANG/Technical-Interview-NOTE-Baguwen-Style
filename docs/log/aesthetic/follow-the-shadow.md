以前我判断"光线好不好"只有一个标准：**亮不亮**。

所以最喜欢正午，最讨厌背光。觉得背光就是拍坏了——人黑成一片，背后白得刺眼。结果是有很长一段时间，我的照片都很清楚，但没有一张让人想再看一眼。

## 光的方向只有三种

**顺光**：光从我背后出去，正对主体。清楚、安全、不出错，但也最容易平。拍证件照、拍记录，够用。

**侧光**：光从侧面来，一半亮一半暗。结构、质感、形状，全靠这种光。同一张脸，正脸光显平，四十五度侧光就有了轮廓。

**逆光**：光朝我这边来。最有氛围，也最容易翻车。主体容易黑，容易糊，容易让人怀疑是不是曝光设错了。

我现在最喜欢的反倒是侧光——不极端的侧光。斜四十五度左右，明暗都有，但还留着细节。这样的光在一天里出现两次，早上和傍晚，各半小时到一小时。

## 手机在逆光时会帮倒忙

这件事我别扭了很久。

逆光好看的地方在于：**亮的地方亮到失去细节，暗的地方留成剪影**。轮廓被勾出来，情绪就在那道边上。

但手机默认会 HDR——把暗部提亮、把高光压下来，把两头都拽回中间。技术上是"更正确"的曝光，可逆光的那股味道被拉平了。

作为天天跟 ISP 打交道的人，我知道这是 tone mapping 在按它的策略干活，没什么可抱怨的。但那属于另一个分区的事。这里只说办法：

- 点屏幕对焦到主体，然后**把曝光滑块往下拖**，直到背景过曝、主体暗下去
- 或者开专业模式，手动降 EV
- 想要真正的剪影，就对着亮的地方测光，让主体彻底黑掉

关键是想清楚：这张我要的是**信息**，还是**氛围**。要信息就让算法帮忙，要氛围就得自己压回去。

## 影子是光的签名

判断光从哪来，最快的办法不是抬头看太阳，是**低头看影子**。

| 影子的样子 | 说明 |
|---|---|
| 几乎没有影子，或者只在正下方一小圈 | 顶光，正午前后，最平 |
| 影子很长，斜着拉出去 | 侧光，早晚，最好用 |
| 完全没有影子 | 阴天（柔光）或纯逆光 |
| 影子边缘很硬 | 直射光，对比强，容易出结构也容易出脏边 |
| 影子边缘发虚 | 散射光，皮肤友好，氛围偏软 |

阴天不是坏天气。阴天等于一个巨大的柔光箱，影子消失、对比变低、颜色变浓。适合拍人、拍静物、拍细节。不适合拍需要"气势"的风景——没有光的方向，风景就少了骨架。

## 一个练习

绕着一个东西走一圈——一棵树、一辆车、一个站着不动的人——每四十五度拍一张，八张。回家按顺序看。

你会发现同一个物体在一天里能被光写成八种完全不同的东西。我第一次做这个练习是在小区里对着一辆共享单车，走完一圈拍了八张，有六张很难看，但有一张我到现在还记得是哪个角度。

## 现在出门的动作顺序变了

以前是：看到什么 → 掏手机 → 拍。
现在是：**看地** → 看影子往哪边倒 → 判断光的方向和软硬 → 走过去，让主体站在我想要的那一侧 → 拍。

慢了很多，废片率没降多少，但"能看"的那几张，基本都是从这一步开始的。
